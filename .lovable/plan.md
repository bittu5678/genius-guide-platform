# CoachingApp interface plan

## Build
- Recreate the supplied CoachingApp logo as a clean reusable asset and place it on login, navigation, and sidebars.
- Replace the placeholder with a polished login screen including Admin/Student selection, email or mobile, password, remember me, forgot-password feedback, and sign-in.
- Add distinct Admin and Student dashboards with the requested navigation, summary cards, charts, progress indicators, activities, and upcoming exams using demo data.
- Add responsive desktop, tablet, and mobile navigation, light/dark theme switching, subtle transitions, and persistent demo sign-in until logout.

## Visual direction
- Dark-blue and white SaaS aesthetic with restrained blue/orange accents, 20px glass-like surfaces, soft shadows, Poppins typography, and Lucide icons.
- Keep the layout original rather than reproducing the uploaded poster.

## Technical details
- React and TypeScript within the existing TanStack app.
- Browser-only demo session and theme persistence; no database or external backend.
- Route-specific metadata and accessibility-conscious controls.

## Verification
- Check login-to-dashboard and logout flows for both roles.
- Verify light and dark themes at desktop and mobile sizes.
- Confirm the generated preview has no build or browser errors.
